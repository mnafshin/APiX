# Contributor Learning Path

This page recommends a concise reading order for new contributors to get productive quickly.

## Beginner (first 1–2 hours)
- README.md — high-level project goals and quickrun
- docs/getting-started.md — follow the "first capture" workflow
- docs/concepts/request-flow.md — minimal request lifecycle overview

## Intermediate (first day)
- docs/how-to/breakpoints.md — how breakpoints work and how to write rules
- docs/how-to/replay.md — replaying captured requests and comparing responses
- docs/dev/setup.md — local development, building engine & CLI

## Deep dive
- docs/architecture.md — internal architecture and components
- docs/plugins.md — plugin runtime and extension points
- pkg/api/proto/apix.proto — gRPC API (source of truth)

## Notes
- Each linked page should state its assumed prior knowledge and what to read next.
- Beginner links aim for actionable workflows; deeper pages are references.
